# Contacts App

Android-приложение для просмотра контактов устройства и звонка по нажатию на контакт.

## Функциональность

- Список контактов устройства, сгруппированных по алфавиту
- Звонок по нажатию на контакт


## Требования

- Android 6.0+ (API 23+)
- Разрешения: `READ_CONTACTS`, `CALL_PHONE`


## Тесты

```bash
./gradlew test
```
